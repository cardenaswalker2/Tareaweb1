Guía de Capturas de Evidencias - ClínicaApp

Para que la página web muestre las imágenes reales en la sección de Evidencias Técnicas, guarda tus capturas de pantalla en esta carpeta con los siguientes nombres:

1. evidencia01.png -> Captura del árbol de carpetas de tu IDE (config, controller, service, repository, etc.).
2. evidencia02.png -> Captura de UsuarioController.java mostrando la inyección directa de repositorios.
3. evidencia03.png -> Captura de ApiSystemController.java mostrando la validación estática de credenciales (asegúrate de tachar/censurar el PIN).
4. evidencia04.png -> Captura de SecurityConfig.java mostrando la directiva CSRF desactivada o WebConfig.java con allowedOrigins("*").
5. evidencia05.png -> Captura de la terminal mostrando el fallo de mvnw test debido al MongoTimeoutException.

Si la página web no encuentra estas imágenes en esta carpeta, mostrará automáticamente un diseño interactivo de "Captura Pendiente" con indicaciones detalladas de qué capturar.
